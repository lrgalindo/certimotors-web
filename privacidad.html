Aviso de privacidad

Responsable

CERTIMOTORS gestiona los datos enviados desde certimotors.com para coordinar solicitudes de inspección vehicular.

Datos que recopilamos

El formulario solicita nombre, teléfono, correo electrónico, placa, zona o municipio y, de forma opcional, marca, modelo, año y fecha preferida. El proveedor de pagos procesa la información necesaria para completar el cobro; CERTIMOTORS no solicita datos de tarjeta dentro de este sitio.

Para qué se usan

Usamos los datos para registrar la solicitud, coordinar la inspección, crear el enlace de pago, dar seguimiento por WhatsApp y entregar el servicio solicitado.

Proveedores

El sitio se publica mediante GitHub Pages. Las solicitudes se envían al servicio de CERTIMOTORS alojado en Render y el pago continúa en Recurrente. Google Analytics, Meta Pixel y TikTok Pixel solo se cargan después de que la persona acepta las cookies de analítica.

Consultas y contacto

Puedes comunicarte con CERTIMOTORS por WhatsApp para realizar una consulta relacionada con tus datos o con el uso de este sitio.
